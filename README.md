# slidoku

a sudoku game where you slide 3×3 boxes to solve the puzzle

## features

- easy, medium, and hard modes
- notes, undo/redo, hints, and solution reveal
- timer, move counters, and keyboard shortcuts
- saves progress in your browser

## play

(https://slidoku.vercel.app/)

## controls

- arrow keys: move between cells
- numbers: enter a value
- `n`: toggle notes
- `ctrl+z` / `ctrl+y`: undo / redo

## privacy

no account or server required; game data stays in browser storage
